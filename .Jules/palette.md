# Palette Journal
## 2026-05-21 - Dual-Encoding for Financial Signals
**Learning:** Color alone is insufficient for critical signals. Using icons (▲/▼) + color + ARIA labels ensures clarity for color-blind users and screen readers.
**Action:** Use icons, color, and ARIA for status indicators.

## 2026-05-21 - Signal Trust and Actionability
**Learning:** Providing explicit confidence metrics (like a strength meter) and user-initiated actions (like a refresh button) increases user trust and engagement in financial dashboards.
**Action:** Include confidence levels and actionable feedback loops in real-time interfaces.
