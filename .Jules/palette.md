## 2026-05-04 - Accessible Repository Documentation
**Learning:** Emojis in documentation should be wrapped in `<span role="img" aria-label="...">` to ensure they are accessible to screen readers, providing context for the visual symbols used. Explicit HTML anchors and "Back to top" links improve navigation and orientation for users within long documents.
**Action:** Always wrap emojis in accessible spans and provide clear internal navigation anchors in any repository documentation or UI text.
