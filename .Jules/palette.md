# Palette Journal
## 2026-05-21 - Learnings
- **Dual-Encoding:** Color alone is insufficient; icons + ARIA are required for signals.
- **Shortcuts:** [R]/[C] shortcuts improve accessibility; visual hints are key for discovery.
- **Async A11y:** Update `aria-valuenow` and labels manually during async DOM updates.
- **Context:** Tab titles and confidence tiers provide low-friction feedback.
- **Momentum:** Trend indicators (↑/↓) provide crucial historical context at a glance.
- **Perf:** Use `textContent` and specific IDs instead of `innerHTML` for updates.
- **Transient UX:** Use 'Copied!' states for fire-and-forget interactions.
- **Live Status:** Pulsing indicators reassure connectivity; use `setAttribute` for A11y.
- **Shortcut Safety:** Check for modifier keys (Ctrl/Cmd) to avoid hijacking browser defaults.
