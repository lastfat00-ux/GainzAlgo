## 2025-05-14 - Documentation as Micro-UX
**Learning:** In an empty or newly initialized repository, the most impactful micro-UX improvement is providing clear, accessible, and navigable documentation. It reduces the "blank canvas" friction for new developers and ensures the project's purpose is immediately understandable to all users, including those using assistive technologies.
**Action:** Prioritize a high-quality README.md with accessible navigation anchors and ARIA labels for non-text elements when starting a project from scratch.
