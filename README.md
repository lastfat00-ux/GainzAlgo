## UX Standards <span role="img" aria-label="artist palette">🎨</span>
- **Semantic HTML:** Use proper elements for structure.
- **ARIA Labels:** Mandatory for all icon-only controls.
- **Keyboard First:** All interactions must be keyboard accessible.
- **Color Contrast:** All text and UI elements must meet WCAG AA standards.
- **Reduced Motion:** Respect `prefers-reduced-motion` media queries.
