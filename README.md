## <a id="mission"></a><span role="img" aria-label="target">🎯</span> Mission
Our mission is to democratize algorithmic trading by providing clear, accessible, and actionable market signals. We believe that powerful trading tools should be intuitive and pleasant to use for everyone.

## <a id="ux-standards"></a><span role="img" aria-label="artist palette">🎨</span> UX Standards
We follow strict UX and accessibility standards to ensure GainzAlgo is a delight to use:
- **Accessibility First**: Every component must be keyboard navigable and screen-reader friendly.
- **Clarity**: Market data can be complex; our UI aims to simplify without losing depth.
