## <a id="ux-standards"></a><span role="img" aria-label="artist palette">🎨</span> UX & Accessibility Standards

At GainzAlgo, we believe that **Accessibility is not optional**. All contributions should adhere to the following micro-UX principles:

- **Semantic Clarity:** Use proper headings and list structures to ensure screen reader compatibility.
- **Visual Feedback:** All interactive elements must have clear hover, focus, and active states.
- **Accessible Controls:** Icon-only buttons must have descriptive `aria-label` attributes.
- **Contrast & Legibility:** Maintain high color contrast for all text and critical UI elements.
- **Keyboard Navigation:** Ensure all functionality is accessible via keyboard, with a logical tab order.

## <a id="getting-started"></a><span role="img" aria-label="rocket">🚀</span> Getting Started

Currently, this repository is in its initial setup phase.

### Development Commands

While the project is being initialized, the following standard commands are planned for use with `pnpm`:

- `pnpm lint`: Checks for TypeScript and ESLint issues.
- `pnpm test`: Runs the test suite.
- `pnpm format`: Auto-formats code with Prettier.
- `pnpm build`: Generates a production build.
